# 💜 Blog - Oficina Gurias of Code

Este projeto foi desenvolvido para uma oficina do **Gurias of Code**, voltada para alunas do **Ensino Médio** que estão iniciando seus estudos em desenvolvimento web.

O repositório também serve como material de apoio para as **monitoras da oficina**, reunindo em um único lugar os exemplos, componentes e arquivos utilizados durante a atividade.

A proposta é apresentar, de forma prática e acessível, conceitos básicos de **HTML, CSS e JavaScript** por meio da construção e personalização de um blog.

---

## 🚀 Como utilizar o projeto

Não é necessário instalar dependências, bibliotecas ou realizar configurações adicionais.

Todo o material necessário para a oficina já está disponível e organizado dentro deste repositório.

Para começar:

1. Clone ou baixe este repositório.
2. Abra a pasta no **Visual Studio Code**.
3. Abra o arquivo `index.html` no navegador.
4. Siga as etapas disponíveis na pasta `codigos/`.
5. Escolha os componentes desejados e personalize o seu blog.
6. Utilize os arquivos `css/style.css` e `js/main.js` para as atividades de CSS e JavaScript.

> 💡 A proposta da oficina é experimentar. Textos, imagens, cores e componentes podem ser modificados para que cada aluna crie sua própria versão do blog.

## 👩‍💻 Orientações para as monitoras

Este repositório também foi organizado para servir como **material de apoio durante a aplicação da oficina**.

A sequência das pastas representa a ordem sugerida para a atividade:

```text
01-navbar
    ↓
02-hero
    ↓
03-cards
    ↓
04-rodape
    ↓
05-javascript
```

Cada etapa possui exemplos previamente preparados para facilitar a explicação e permitir que as participantes experimentem diferentes possibilidades.

As monitoras podem utilizar os arquivos da pasta `codigos/` como referência durante a oficina, auxiliando as alunas na escolha, inserção e personalização dos componentes.

O objetivo não é que as participantes precisem desenvolver toda a página do zero.

A proposta é que elas consigam:

- compreender a estrutura básica de uma página web;
- identificar elementos HTML;
- realizar alterações no código;
- personalizar textos, cores e imagens;
- compreender o papel do CSS;
- ter um primeiro contato com JavaScript;
- visualizar imediatamente o resultado das alterações realizadas.

Dessa forma, a oficina busca proporcionar uma experiência prática e introdutória com desenvolvimento web.

---

## 💻 Tecnologias utilizadas

O projeto utiliza:

- **HTML** — estrutura das páginas;
- **CSS** — estilização e personalização;
- **JavaScript** — introdução à interatividade;
- **Tailwind CSS** — apoio na construção e responsividade dos componentes.

O foco da oficina está principalmente no **desenvolvimento Front-end**, com uma pequena introdução ao JavaScript.

---

## 🎯 Objetivo da oficina

Ao final da atividade, espera-se que as participantes tenham tido contato prático com conceitos básicos de desenvolvimento web e consigam compreender como **HTML, CSS e JavaScript trabalham juntos na construção de uma página**.

Mais do que criar um blog pronto, a proposta é incentivar a experimentação, permitindo que cada participante modifique o projeto e crie uma versão com sua própria identidade.

## 💜 Sobre o Gurias of Code

O **Gurias of Code** busca aproximar meninas e jovens da área de tecnologia por meio de atividades práticas e experiências com programação.
